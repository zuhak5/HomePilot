# Repository License Decision

## Status

No root `LICENSE` file is currently present. Until the copyright holder selects and adds a license, external users should not infer permission to copy, modify, distribute, sublicense, or commercially use HomePilot merely because the repository is public.

This document records the decision that still needs owner approval; it does not grant a license.

## Decision questions

The repository owner should decide:

1. Whether the source should be open source, source-available, or all-rights-reserved.
2. Whether commercial use and redistribution are allowed.
3. Whether modifications must be disclosed or distributed under the same terms.
4. Whether patents, trademarks, branding, app-store binaries, signing material, and hosted services need separate treatment.
5. Whether dependencies, fonts, images, illustrations, audio, and generated assets are compatible with the selected license.
6. Whether contributions require a Developer Certificate of Origin or contributor agreement.

## Common options for legal review

- MIT or BSD-3-Clause: permissive source use with attribution and warranty disclaimer.
- Apache-2.0: permissive use with an express patent license and notice requirements.
- GPL/AGPL families: reciprocal obligations that require careful distribution and hosted-service analysis.
- Proprietary/all-rights-reserved: public source visibility without broad reuse permission.

This list is informational and not legal advice.

## Before adding a license

- Inventory third-party code and assets.
- Confirm ownership of all original contributions.
- Review package and asset licenses.
- Decide how the HomePilot name, icon, and VersionDeck branding may be used.
- Decide whether released APKs and hosted backend/site components use the same terms.
- Update `README.md`, contribution policy, and release packaging.

## Completion

Once approved, add the exact root `LICENSE` text, update this document to record the decision and date, and add any required `NOTICE`, attribution, or contributor-signoff files.
